# WhyWorks – Premium Doctor Portfolio Demo

A responsive single-page doctor/clinic portfolio website demo built with HTML, CSS and vanilla JavaScript.

## Preview
Open `index.html` in a browser. Google Fonts and Unsplash photos require an internet connection.

## Customize before showing to a real client
Search and replace the sample details in `index.html`:
- Dr. Aarya Mehta – sample doctor name
- MBBS, MD (General Medicine) – sample qualification
- 10+ years – sample experience
- Mehta Health Centre / Nanded – sample clinic and location
- +91 98765 43210 – sample phone number
- Consultation timings and services

All doctor information and clinic details are fictional placeholders. Do not publish them as real claims. Replace with verified details and obtain the doctor's approval for photos, qualifications, services and testimonials.

## Appointment form
The form currently displays a demo confirmation only. It does not send or store patient data. Before production, connect it to a secure backend, approved booking provider, clinic email or WhatsApp workflow. Avoid collecting sensitive medical details in an unsecured form.

## Files
- `index.html` – page structure and content
- `styles.css` – visual design and responsive layout
- `script.js` – mobile navigation and demo form interaction

## Deployment
Upload the folder to Netlify, Vercel static hosting or any standard static web host. No build step is required.

Created as a sales/demo concept for WhyWorks.
